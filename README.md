One roast line about a gadget used every day, a single line under 200 characters.

> My earbuds case died before the earbuds did, so now I carry a tiny coffin for two perfectly healthy earbuds.

## Run

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (108 characters, deterministic — the same bytes on every run).
